# 평가 보고서 계산 기준 변경 내역 — 2026-09-15

## 적용 결과

- 차수 점수와 영역 점수: (AI + 선생님 × 2) ÷ 3.
- AI 평가 총점과 선생님 평가 총점: (1차 + 2차 × 2) ÷ 3.
- 최종 점수: (AI 평가 총점 + 선생님 평가 총점 × 2) ÷ 3.
- 계산 중간 값은 반올림하지 않으며 표시만 소수 첫째 자리로 반올림, 소수점 0은 생략.
- 2차 점수가 높을 때만 “OO점 향상되었어요.” 표시. 감소·동일 안내는 표시하지 않음.
- 2차 보고서에 평가 주체별 점수 추가. 1차·2차 모두 해당 차수에 맞는 산출 방법 안내 표시.
- 그래프와 점수표의 계산을 통일하고 영역별 득점/배점 및 성취도 표시.
- 평가표·그래프의 “구성 및 조직력” → “구성과 조직력”, “구체성” → “감상의 구체성”.
- 기존 생성 보고서도 같은 가중치 적용. 원점수·평가 배점·설명·작성글·피드백·처리 이력은 보존.
- 저장된 총평 본문은 자동으로 고치지 않음. 새로 생성하는 샘플 총평의 영역명부터 새 명칭 사용.
- 커밋·푸시·Firebase 배포는 하지 않음.

## 명세 확인 범위

기본 명세 본문과 AI 프롬프트 2개, 연결된 하위 명세 4개(본사관리자·학생 프론트·기관관리자·평가 보고서)를 끝까지 확인했습니다.
관련 문구만 수정한 뒤 다섯 페이지를 다시 조회하여 반영 결과와 비수정 내용 보존을 대조했습니다.
Notion의 링크 표시와 기호 이스케이프 정규화를 제외하면 계획한 변경 내용과 모두 일치합니다.

- src/lib/review-score-policy.ts: 공통 계산식·표시 형식·배지·산출 안내.
- src/lib/review-domain.ts: 저장 시 계산, 기존 보고서의 파생 점수 갱신, 새 샘플 총평의 영역명.

- tests/review-score-policy.test.ts 및 관련 기존 테스트: 계산·소급 적용·원본 보존·표시 정책 검증.

## 검증 결과

- 기존 저장 보고서 11건: 모두 새 계산 버전 적용, 영역 점수 합계와 총점 일치.
- 1차 보고서: AI 70점·선생님 80점 → 1차 76.7점 확인.
- 2차 보고서: 1차 76.7점·2차 87.3점·최종 83.8점 확인(계산에는 반올림 전 값 사용).
- 기관관리자 2차 평가 화면과 보고서 점수 일치, 명칭·계산 도움말 확인.
- 변경 파일 ESLint 및 TypeScript 검사 통과.
- 전체 자동 테스트 73개 중 71개 통과. 기존 실패 2개는 review-seed-mapping.test.cjs의 도서 연결 불일치(남몰래 거울 / 901호 예시 기대값)로 이번 변경 범위 밖.
- 새 산출 안내·평가 주체별 점수는 인쇄 공통 본문 및 인쇄 CSS에 포함. 실제 인쇄 대화상자/PDF 생성은 이번 검증에 포함하지 않음.
