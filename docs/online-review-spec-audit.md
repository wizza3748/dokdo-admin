# 온라인 독후감 단계별 명세 대조·검증

## 작업 규칙

각 단계는 구현 → 해당 명세 재확인 → 정적 검사·동작 검사 → 불일치 보완 순서로 진행한다. 전체 단계 종료 후 상위·하위 명세 전체를 다시 읽고 전체 회귀 검증한다. 코드에 존재하는 것과 브라우저로 통과한 것은 구분한다. 전체 프로젝트 완료를 이 문서의 일부 통과만으로 판단하지 않는다.

디자인 변경은 승인 범위만 적용한다. 이번 승인: 완성 화면 기능별 버튼 묶음, 목록 카드 안 보고서·비교 버튼, 보고서 설정 스위치, 모바일 헤더 겹침·탭 넘침, 보고서·외부 공유의 관리자 메뉴 제외. 명세 원문 수정·커밋·푸시·배포 없음.

## 목 데이터와 기존 진행 이력

- 보고서가 포함된 기본 샘플은 생성 당시 보고서 사용 설정을 가진 이력이다. 현재 본사 설정이 미사용이어도 과거 보고서를 삭제하지 않는다.
- 신규 템플릿 기본값은 미사용이며, 기존 저장된 명시적 사용/미사용 설정이 우선한다.
- 사용자 지정 기본 목 설정으로 이름에 `통합형 독서록`이 포함된 기존 8개 템플릿은 모두 보고서 사용이다. 다른 템플릿 및 이후 본사에서 명시적으로 저장한 설정은 유지한다. 학생 reading-718-round-1에서 해당 `독서록 쓰기` 선택 시 4개 질문과 평가 보고서 제공 표시를 확인했다. 작성 시작·제출은 하지 않았다.
- 학생 홈 초기화 버튼과 기존 저장 키 삭제 흐름은 이번 단계에서 수정하지 않았다. 진행중 사용자 데이터를 지우지 않기 위해 실제 전체 초기화는 실행하지 않았다. 초기화 후 기본 데이터 재구성은 순수 도메인 테스트로 검사했다.
- 테스트 과정에서 템플릿 43 설정은 원래 사용 상태로 복원했다. 학생의 작성글 제출, 실서버 AI·발송·지급은 실행하지 않았다.

## 전체 명세 대조에서 남은 항목 (완료로 처리하지 않음)

- 실제 AI 프롬프트·최종 보고서 디자인·저학년 상세 평가표는 본사 확정 자료 필요. 현재 샘플 AI와 교체 가능한 보고서 구조다.
- 독서로 연결은 통합검색 화면 fallback이다. 도서 ID/ISBN 및 교육청 지역별 검색 결과 연결은 아직 외부 연동 검증이 필요하다.
- 실제 인증, 외부 공유 서명·만료, 학부모 메시지 전송은 로컬 프로토타입 상태 처리이며 운영 연동이 아니다.
- 학생 이미지 첨부와 피드백의 이미지 표시, 관리자 상세의 기존 전자책·길라잡이 영역 및 모든 기존 도구 유지 여부는 전체 단계 완료 전 별도 보완·검증이 필요하다.
- 모든 사용자·상태 조합에 대한 브라우저 회귀를 도메인 테스트만으로 대체하지 않는다. 이번 검증된 경로 외 범위는 전체 완료 판정 보류다.
