# AI 프롬프트 로컬 반영

- 원본: 독도 피드백 프롬프트(연구소 공유), 260922 1차·2차 탭. 2026-09-28 확인.
- `src/lib/review-prompts/round-1.ts`, `round-2.ts`: 각 탭 본문 전체를 수정 없이 보관. 문서 변경을 자동 동기화하지 않음.
- `src/lib/review-prompts/index.ts`: 차수별 원문 선택과 입력 구성. 지침과 학생 입력을 별도 메시지로 분리. 2차에는 1차 작성 형태·글·채점 결과·보고서 총평·선생님용 피드백을 포함.
- `src/lib/review-ai-preview.ts`: 기관 상세의 새 생성 결과에 사용하는 **형식 확인용 샘플**. 항목별보기는 총평과 항목별 피드백, 이어보기는 총평과 강점과 보완할 점. 미션·성장 요약 구획과 근거 없이 고정한 2차 반영 라벨을 사용하지 않음.
- 과거 샘플 복원 함수와 기존 저장·전송 자료는 유지. 이전 자료를 자동 재생성하지 않음. 일괄 처리 분기는 기존 요청에 따라 변경하지 않음.

## 실제 AI 연결과의 구분

외부 AI 호출, 비용 발생, API 키 설정은 추가하지 않았다. 새 샘플도 실제 학생 글을 채점하거나 1차 대비 변화를 분석한 결과가 아니다. 기존 샘플 점수를 유지한다. 8개 기준 채점, 채점 불가 판단, 2차 독립 채점·비교, 조건부 반영 라벨은 원문에 보존되어 있으나 아직 실행되지 않는다.

실제 서비스 연결 시 검증된 줄거리와 1차 자료를 입력하고, 원문의 8개 세부 점수와 5개 영역 점수를 검증하여 현재 결과 저장 구조에 연결해야 한다. 현재 로컬에는 영역별 AI 점수만 있으므로 없는 1차 세부 점수를 임의로 역산해서는 안 된다.

Google Docs와 Notion 명세는 수정하지 않았다.
