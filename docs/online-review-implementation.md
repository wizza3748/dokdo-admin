# 온라인 독후감 피드백 구현 계획

기준: 2026-09-07 Notion 최상위 3c63ad44a0b9807a8912e4648419f4dc 및 본사관리자·학생·기관/학급관리자·평가 보고서 하위 명세 전체.

## 비교 결과

- 기존 학생 runtime은 answers 배열 하나를 고쳐쓰기에도 재사용하여 차수 및 최종 본문 구분 없음.
- 관리자 피드백은 총평 텍스트 하나이며 AI 실패 이력, 평가, 보고서가 없음.
- 템플릿 관리 저장은 화면 내 상태 위주이므로 공통 영속 설정 필요.
- 현행 반려는 답변을 지움. 최신 정책은 동일 레코드/본문 보존 및 AI 최초 실행부터 차단.
- 기존 섬초롱꽃은 작성전에도 가능. 최신 정책은 저장완료 이후만 허용.

## 구현 순서

1. 공통 독후감/별도 차수 레코드, 불변 스냅샷, 처리 가드, AI 어댑터, 점수 계산 및 테스트.
2. 템플릿 보고서 설정/검색/컬럼 저장, 기준 시트 안내 문구(43 유지, 63 정규화).
3. 학생 작성/고쳐쓰기 영속화, 참고 패널, 제출/피드백 확인 및 2차 진입.
4. 기관/학급 관리자 차수별 평가/피드백/처리, 읽기 전용 본사 상세.
5. 목록/알림/보고서/비교/공유 진입 및 초기화 연동.
6. 타입/린트/빌드/상태 전이 테스트 및 로컬 브라우저 PC·태블릿·모바일 확인.

## 원칙과 미확정 사항

- 기존 라우트와 디자인 컴포넌트를 재사용. Notion 문서 수정 및 외부 배포 금지.
- AI는 외부 호출 없는 교체 가능한 프로토타입 어댑터. 최종 평가 프롬프트/보고서 디자인 추후 교체.
- 1~2레벨 세부 평가 기준은 원문 미제공. 확정된 영역별 배점만 적용하며 임의 세부 기준을 만들지 않음.
- 기존 진행 건은 기존 흐름 유지, 새로 시작한 독후감부터 신규 기능 적용(사용자 확인 완료).
- 신규 상태는 로컬 전용 mock API의 `.local-state/online-reviews.json`에 저장해 개발 서버 재시작 후에도 유지. 실제 인증 대신 명시적 데모 사용자 컨텍스트를 쓰며 운영 인증은 외부 연동 대상.
- 기존 전송완료/완료 건은 1차 이력 보존, 2차/보고서 소급 생성 금지.
- 범위 외 기존 수정 src/app/page.tsx 및 .codex 로그 보존.
- 디자인 변경 사전 승인: 기존 학생 화면의 책 표지·카드 배치·헤더·에디터/하단 버튼·노란 확인 모달을 재사용. 사용자가 승인한 추가 범위는 보고서 제공 표시, 고쳐쓰기 우측 안내/항목별 패널, 2차/보고서/작성글 비교 버튼에 한정한다.
