## 출력 대응과 검증

| 명세·프롬프트 항목 | 보존·화면 연결 |
| --- | --- |
| `message` | `body`; 일반 텍스트 저장/복사, 줄바꿈 유지 |
| `composition_type`, `focus` | `composition`, `focus`; 일반형 구성과 실제 전개를 연결. 짧은 두 유형은 유형 유지 |
| `evidence.point/source` | `evidence[].point/source`; 주장 문장과 `references(recordId,field,quote)`로 입력 위치 연결 |
| `used.peer_comparison/teaching_effect` | `peerComparison`, `teachingOutcome`; 조건·근거가 있는 예시와 없는 예시 분리 |
| `carry_over.item/new/continued` | `carry[].text/continued`; 전월 발송 확정 항목을 개별 비교. 완료 근거가 있으면 새 목표 |
| `review_spans` | 본문과 정확히 일치하는 `text/reason`만 보존, 최대 3개 |
| `notes_for_teacher` | `notesForTeacher`; 생성 결과와 함께 저장, 기관/본사 근거에서 표시 |
| 서버 계산 글자 수 | `charCount`, 기존 화면 `monthlyLength`; 줄바꿈 제외, 코드포인트 수 |
| 적용 버전 | `promptVersion`; 새 생성본에만 보존 |

- JSON 구조와 문구 검증을 구분한다. 같은 입력으로 자동 재생성은 1회만 한다. 2차 문구 실패는 결과와 확인 안내를 보존하고, 2차 JSON 실패는 생성 실패로 처리한다.
- 자동 검증 재생성은 사용자 다시 만들기 횟수에 별도로 가산하지 않는다. 사용자 작업 성공 시 기존대로 한 번 차감한다.
- 그림 이모지, 금지 기호, 내부 용어, 통계형 표현, 유형별 길이와 구성, 근거 위치, 인용 일치, 검토 표시를 검사한다.
- 인용 내 마침표·물음표로 문장을 자르지 않는다. 인용 서술어·다음 계획·가정 팁과 유형별 최소 길이를 보호한다.
- 직접 질문 요청과 명시적인 문구 교체, 표현 방향을 지원한다. 지원하지 않는 자유로운 내용 요청은 반영했다고 주장하지 않고 교사 확인 사항에 남긴다.

## 보존 및 실제 검증

- 독립 로컬 QA 저장소(3100)와 새 브라우저 소유자 쿠키에서 검증했다. 공용 데이터/다른 브라우저 결과/학생프론트 전용 데이터를 초기화하지 않았다.
- 기관 박프로: 직접 질문 요청 반영, 그림 이모지 제외, `^^` 1회, 생성 중 표시, 교체 취소 시 요청 유지, 미저장 예시 이동 취소 시 본문·선택 유지, 저장본과 클립보드 일치, 발송 완료 후 읽기 전용 확인.
- 본사 동일 예시: 박프로 발송 시각과 10명 중 발송 완료 4명/미발송 6명/40.0% 반영. 새로고침 뒤 유지. 선택한 생성본과 동일한 근거 조회 확인.
- 말투: 빈 상태·빈 변경 이력, 3편 적용, 항목 수정 저장과 이전/이후 이력, 미저장 이동 취소 시 입력·예시 유지 확인.
- API 검증 13개 흐름: 저장·복사·발송 실패 후 재시도, 소유자 격리, 본사 반영, 개별 초기화, 생성 실패 횟수 보존, 말투 실패 시 발송 유지, 본사 작성 차단, 0~3편·사용 끄기, 복수 학원/21명, 생성 경계, 12월 자료/재진입 유지.
- 기존 주간 목록·월별 권수·관리 메모·학생 테스트 저장소/문맥 테스트를 영향 범위로 실행했다. 관련 없는 화면을 재설계하지 않았다.
- 현재 3000번 로컬에는 관리 건과 연결되지 않은 학생 자료도 있어 학습 자료 예시 준비 시 오류가 발생했다. 새 전용 예시를 만드는 경우에만 연결된 학생을 우선 사용하도록 수정했다. 기존 공용 데이터와 저장된 예시 결과는 변경하지 않는다.
- 실제 로컬 원본을 메모리에서 복제하여 날짜 3개 × 세부 항목 13개, 총 39개 예시 준비 성공을 확인했다. 준비 전후 원본 내용이 같음을 검사했다. 3000번 로컬에서도 검증 도구 선택 후 장프로 학생 상세 진입과 기존 왼쪽 이용 내역 표 표시를 확인했다.

## 확인 범위의 한계

이 구현은 실제 모델이 아닌 **규칙 기반 모의 생성**이다. 기간 전체 자료에서 정해진 학습 주제·비교 기준을 추출하고 실제 입력 인용을 연결하지만, 임의의 한국어 의미 해석·교육적 적합성·전월 표현 중복·자유로운 요청의 생성 품질을 완전히 보장하지 않는다. 실제 모델의 v1.4 품질 검증 완료로 볼 수 없다.

인용 문자열과 근거 위치는 자동 검사하고, 대표 전후 글·이전 학원 사례를 수동 확인했다. 모든 가능한 글에서 주장과 근거가 의미상 타당한지는 실제 모델 연동 이후 별도 검증 대상이다. 내용·사실 정정이 말투로 전파되지 않는 대표 예시는 통과했지만 임의의 표현 스타일을 모두 학습하는 기능은 아니다.

관련 없는 기존 로컬 파일 저장소에서 `rename EPERM` 파일 잠금이 1회 관찰되었다. API 검증기는 이 운영체제 파일 잠금만 재시도했고 성공했다. 월간 저장 실패 주입과 구분하여 기록하며 공용 저장소 코드는 수정하지 않았다.
